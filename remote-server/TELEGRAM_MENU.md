# Menu Telegram v1.5

Setelah bot aktif dan admin dipasangkan, kirim `/menu` atau tekan tombol menu.

## Tombol

- **🔑 Buat Kode Aktivasi**: memilih Video Mixer atau Remote HP, lalu membuat kode berlaku 1 jam.
- **📊 Status Sistem**: server, scheduler, Telegram, Cloudflare, backup, jumlah device, sesi, dan kecurigaan.
- **💻 Device**: daftar device dan detailnya.
- **🧾 Kode Aktif**: kode pending beserta tombol batalkan.
- **⚠️ Keamanan**: kejadian mencurigakan dengan tindakan abaikan atau revoke.

Perintah teks lama tetap tersedia untuk kebutuhan teknis.
