1

Buat tunnel dan salin perintah

  1. Di Cloudflare buka Networking → Tunnels → Create a Tunnel.
  2. Beri nama tunnel, lalu pilih Docker.
  3. Klik ikon salin pada perintah docker run ... --token eyJ....
  4. Jangan jalankan perintahnya. Tempel seluruh perintah ke kolom di bawah; server akan mengambil token secara otomatis.
2

Hubungkan connector

Aktifkan Cloudflare, pilih mode Auto, lalu simpan. Tunggu sampai status menjadi Terhubung.

3

Buat alamat HTTPS

  1. Di tunnel Cloudflare buka Routes → Add route → Published application.
  2. Pilih subdomain dan domain, misalnya remote.domainkamu.com.
  3. Service type: HTTP.
  4. Service URL: http://server:8000.
  5. Kembali ke web app, isi hostname, simpan, lalu klik Uji alamat HTTPS.
