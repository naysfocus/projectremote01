Kualitas output

Default disetel setara sumber 720p @24fps agar tidak ada upscale/bitrate berlebih — render lebih cepat & file lebih kecil. Naikkan hanya bila sumber Anda memang lebih tinggi. CRF lebih kecil = kualitas lebih tinggi (file lebih besar).

Folder output

Performa

Metode Klasik dipilih sebagai default untuk perilaku paling konservatif dan kompatibel. Metode Cepat menormalisasi tiap klip sekali lalu merangkai output tanpa re-encode; gunakan untuk batch besar bila ingin memangkas waktu proses.

Audio & encoder
File langsung diunggah setelah dipilih.
🎵 0 file audio ter-upload

Audio membentang di 1 video hasil generate secara utuh (bukan per klip). Bila lebih dari 1 file, dipakai bergilir (rolling): output ke-1 → audio ke-1, output ke-2 → audio ke-2, dst, lalu berulang. Jika audio lebih panjang dari video, ujungnya dipotong. Jika lebih pendek, sisa durasi jadi hening (tidak di-loop).

Auto memakai GPU bila terdeteksi dan otomatis fallback ke CPU. Encoder aktif tercatat di log.

Jumlah output

Tanpa limit tetap aktif. Jika hasil melebihi 30.000 video, aplikasi akan meminta konfirmasi sebelum render dimulai.
