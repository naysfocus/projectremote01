# Upgrade Remote HP PC v1.49 → v1.50

1. Tutup Remote HP v1.49.
2. Backup `remote_hp.db`.
3. Gunakan folder `remote-hp-pc` dari `project-remote-v1.0`.
4. Salin `remote_hp.db` lama ke root folder `remote-hp-pc` sebelum pertama kali menjalankan v1.50.
5. Jalankan `setup-windows.bat` sekali bila dependency belum diperbarui.
6. Gunakan `jalankan-windows.bat` untuk mode PC lokal biasa.
7. Gunakan `jalankan-windows-lan.bat` ketika Remote HP Android akan dipakai.

Token aktivasi Remote Server disimpan di profil OS dan normalnya tidak perlu aktivasi ulang. Mobile pairing memakai tabel baru dan tidak mengubah HP, akun, placement atau histori upload.
